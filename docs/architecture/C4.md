# C4 Model — Sistema de Processamento de Vídeos · FIAP X

> O **C4 Model** descreve a arquitetura de software em quatro níveis de abstração progressiva:  
> **Contexto → Containers → Componentes → Código**

---

## Nível 1 — Diagrama de Contexto do Sistema

Mostra o sistema como uma caixa preta e seus relacionamentos com usuários e sistemas externos.

```mermaid
C4Context
    title Sistema de Processamento de Vídeos — Contexto

    Person(user, "Usuário", "Pessoa que envia vídeos\ne consulta o status do processamento")
    Person(admin, "Administrador", "Monitora a saúde\ne métricas do sistema")

    System(fiapx, "FIAP X Video Processor", "Plataforma de processamento assíncrono\nde vídeos com extração de frames em ZIP")

    System_Ext(aws_s3, "Amazon S3", "Armazenamento de objetos:\nvídeos originais e ZIPs gerados")
    System_Ext(aws_sqs, "Amazon SQS", "Fila de mensagens para\ndesacoplar API do processamento")
    System_Ext(email_server, "Servidor SMTP", "Entrega de e-mails\nde notificação de falhas")
    System_Ext(monitoring, "Grafana + Prometheus", "Monitoramento, métricas\ne dashboards operacionais")

    Rel(user, fiapx, "Faz upload de vídeos,\nconsulta status, baixa ZIP", "HTTPS/REST")
    Rel(fiapx, aws_s3, "Armazena/recupera\nvídeos e ZIPs", "AWS SDK / HTTPS")
    Rel(fiapx, aws_sqs, "Publica e consome\nmensagens de processamento", "AWS SDK / HTTPS")
    Rel(fiapx, email_server, "Envia e-mail de\nnotificação de falha", "SMTP")
    Rel(admin, monitoring, "Visualiza métricas\ne alertas", "HTTPS")
    Rel(fiapx, monitoring, "Expõe métricas\nPrometheus", "HTTP /metrics")
```

## Nível 2 — Diagrama de Containers

Detalha os processos/aplicações que compõem o sistema e como se comunicam.

```mermaid
C4Container
    title Sistema de Processamento de Vídeos — Containers

    Person(user, "Usuário", "Interage via REST API")

    System_Boundary(fiapx, "FIAP X Video Processor") {
        Container(api, "API Service", "Node.js / Express.js", "Autenticação JWT, geração de\npresigned URLs, gestão de vídeos\ne exposição de métricas")

        Container(processor, "Processor Service", "Node.js / FFmpeg", "Consumer SQS: baixa vídeo,\nextra frames, gera ZIP\ne faz upload para S3")

        Container(notification, "Notification Service", "Node.js / Nodemailer", "Consumer SQS de falhas:\nenvia e-mail de notificação\npara o usuário afetado")

        ContainerDb(postgres, "PostgreSQL", "PostgreSQL 15", "Persiste usuários\ne status dos vídeos")

        ContainerDb(redis, "Redis", "Redis 7", "Controle de concorrência:\nmax 3 vídeos simultâneos\npor usuário")
    }

    System_Ext(s3, "Amazon S3", "Buckets: hackaton-videos\ne hackaton-zips")
    System_Ext(sqs, "Amazon SQS", "Filas: video-jobs,\nvideo-failures, video-jobs-dlq")
    System_Ext(smtp, "Servidor SMTP", "MailHog (dev)\nou SES (prod)")

    Rel(user, api, "REST API calls", "HTTPS :3001")
    Rel(api, postgres, "Lê/escreve usuários\ne vídeos", "TCP :5432")
    Rel(api, redis, "Controla concorrência\npor usuário", "TCP :6379")
    Rel(api, s3, "Gera presigned URLs\npara upload/download", "AWS SDK")
    Rel(api, sqs, "Publica job de\nprocessamento", "AWS SDK")

    Rel(processor, sqs, "Consome video-jobs\ne publica video-failures", "AWS SDK")
    Rel(processor, s3, "Baixa vídeo original\ne sobe ZIP gerado", "AWS SDK")
    Rel(processor, postgres, "Atualiza status\ndo vídeo", "TCP :5432")

    Rel(notification, sqs, "Consome\nvideo-failures", "AWS SDK")
    Rel(notification, smtp, "Envia e-mail\nde notificação", "SMTP :1025")
```

Detalha os componentes internos do container mais complexo.

```mermaid

    Person(user, "Usuário Autenticado")

    System_Boundary(api, "API Service") {
        Component(auth_routes, "Auth Routes", "Express Router", "POST /auth/register\nPOST /auth/login")

        Component(validate_middleware, "Validate Middleware", "Express Middleware", "Valida schema do request\nbody via Joi/validator")

        Component(auth_controller, "Auth Controller", "Express Handler", "Trata requisições de\nautenticação e registro")
        Component(video_controller, "Video Controller", "Express Handler", "Trata requisições de\ngestão de vídeos")

        Component(auth_service, "Auth Service", "Business Logic", "Lógica de registro,\nlogin e geração de JWT")
        Component(video_service, "Video Service", "Business Logic", "Lógica de upload,\nconfirmação e listagem")

        Component(user_repo, "User Repository", "Data Access", "CRUD de usuários\nno PostgreSQL via Sequelize")
        Component(video_repo, "Video Repository", "Data Access", "CRUD e queries\nde vídeos no PostgreSQL")

        Component(s3_service, "S3 Service", "Infrastructure", "Gera presigned URLs\npara upload e download")

    ContainerDb(redis, "Redis")

    Rel(auth_routes, validate_middleware, "Valida payload")

    Rel(auth_routes, auth_controller, "Delega")
    Rel(video_routes, video_controller, "Delega")

    Rel(auth_controller, auth_service, "Chama")
    Rel(video_controller, video_service, "Chama")

    Rel(video_service, video_repo, "Persiste/consulta\nvídeos")
    Rel(video_service, redis, "Controla\nconcorrência")
    Rel(video_service, s3_service, "Solicita\npresigned URL")
    Rel(video_service, sqs_publisher, "Publica\njob")

    Rel(user_repo, postgres, "SQL via Sequelize")
    Rel(video_repo, postgres, "SQL via Sequelize")

    Rel(sqs_publisher, sqs, "AWS SDK")
```

## Nível 3 — Diagrama de Componentes: Processor Service

```mermaid
C4Component
    title Processor Service — Componentes

    System_Boundary(processor, "Processor Service") {
        Component(worker, "Worker", "Node.js Entry Point", "Inicia o consumer SQS\ne gerencia shutdown gracioso")

        Component(video_consumer, "Video Consumer", "SQS Consumer", "Loop de polling no SQS,\nachieve mensagens e\ndelega ao processorService")

        Component(processor_svc, "Processor Service", "Business Logic", "Orquestra o fluxo:\ndownload → frames → zip\n→ upload → status update")

        Component(s3_downloader, "S3 Downloader", "Infrastructure", "Baixa vídeo original\ndo S3 para disco temporário")

        Component(frame_extractor, "Frame Extractor", "Infrastructure / FFmpeg", "Extrai frames do vídeo\nem 1fps via fluent-ffmpeg")

        Component(zip_service, "Zip Service", "Business Logic", "Compacta frames\nem arquivo ZIP via archiver")

        Component(s3_uploader, "S3 Uploader", "Infrastructure", "Faz upload do ZIP\npara o bucket hackaton-zips")

        Component(sqs_publisher, "SQS Publisher", "Infrastructure", "Publica em video-failures\napós 3 tentativas falhas")

        Component(video_repo, "Video Repository", "Data Access", "Atualiza status do vídeo\n(PROCESSING/COMPLETED/FAILED)")
    }

    System_Ext(sqs_jobs, "SQS video-jobs")
    System_Ext(sqs_fail, "SQS video-failures")
    System_Ext(s3, "Amazon S3")
    ContainerDb(postgres, "PostgreSQL")

    Rel(worker, video_consumer, "Inicia")
    Rel(video_consumer, sqs_jobs, "Long polling / ReceiveMessage")
    Rel(video_consumer, processor_svc, "processVideo(message)")

    Rel(processor_svc, video_repo, "updateStatus()")
    Rel(processor_svc, s3_downloader, "downloadVideo()")
    Rel(processor_svc, frame_extractor, "extractFrames()")
    Rel(processor_svc, zip_service, "createZip()")
    Rel(processor_svc, s3_uploader, "uploadZip()")
    Rel(processor_svc, sqs_publisher, "publishFailure() — após 3x")

    Rel(s3_downloader, s3, "GetObject")
    Rel(s3_uploader, s3, "PutObject")
    Rel(sqs_publisher, sqs_fail, "SendMessage")
    Rel(video_repo, postgres, "SQL via Sequelize")
```

## Nível 3 — Diagrama de Componentes: Notification Service

```mermaid
C4Component
    title Notification Service — Componentes

    System_Boundary(notification, "Notification Service") {
        Component(worker, "Worker", "Node.js Entry Point", "Inicia o consumer e\ngerencia shutdown gracioso")

        Component(failure_consumer, "Failure Consumer", "SQS Consumer", "Polling em video-failures,\ndelega ao notificationService")

        Component(notification_svc, "Notification Service", "Business Logic", "Compõe e envia\ne-mail de falha ao usuário")

        Component(mailer_client, "Mailer Client", "Infrastructure / Nodemailer", "Cria transporter SMTP\ne envia o e-mail")
    }

    System_Ext(sqs, "SQS video-failures")
    System_Ext(smtp, "Servidor SMTP\n(MailHog dev / SES prod)")

    Rel(worker, failure_consumer, "Inicia")
    Rel(failure_consumer, sqs, "ReceiveMessage")
    Rel(failure_consumer, notification_svc, "sendFailureNotification()")
    Rel(notification_svc, mailer_client, "createTransport().sendMail()")
    Rel(mailer_client, smtp, "SMTP")
```

## Nível 4 — Fluxo de Dados: Upload de Vídeo (Sequência)

```mermaid
sequenceDiagram
    actor U as Usuário
    participant A as API Service
    participant R as Redis
    participant DB as PostgreSQL
    participant S3 as Amazon S3
    participant SQS as Amazon SQS
    participant P as Processor
    participant N as Notification

    U->>A: POST /auth/login
    A-->>U: JWT token

    U->>A: POST /videos/upload-url {filename}
    A->>R: INCR concurrent:userId
    A->>DB: INSERT video (status=UPLOADED)
    A->>S3: GeneratePresignedURL (PUT, 5min TTL)
    A-->>U: {videoId, uploadUrl}

    U->>S3: PUT {uploadUrl} (upload direto, sem passar pela API)
    S3-->>U: 200 OK

    U->>A: POST /videos/{videoId}/confirm
    A->>SQS: SendMessage {videoId, userId, s3Key, userEmail}
    A->>DB: UPDATE video SET status='QUEUED'
    A-->>U: {video: {status: 'QUEUED'}}

    loop Polling de status
        U->>A: GET /videos/{videoId}
        A->>DB: SELECT video
        A-->>U: {status: 'QUEUED'|'PROCESSING'|'COMPLETED'|'FAILED'}
    end

    SQS-->>P: ReceiveMessage (long poll)
    P->>DB: UPDATE video SET status='PROCESSING'
    P->>S3: GetObject (download vídeo)
    P->>P: FFmpeg (extrai frames)
    P->>P: Archiver (cria ZIP)
    P->>S3: PutObject (ZIP)
    P->>DB: UPDATE video SET status='COMPLETED', zip_s3_key=...
    P->>R: DECR concurrent:userId
    P->>SQS: DeleteMessage

    U->>A: GET /videos/{videoId}/download-url
    A->>S3: GeneratePresignedURL (GET, 15min TTL)
    A-->>U: {downloadUrl}
    U->>S3: GET {downloadUrl}
    S3-->>U: frames.zip

    note over P,N: Em caso de falha (3 tentativas)
    P->>DB: UPDATE video SET status='FAILED'
    P->>SQS: SendMessage video-failures {videoId, userEmail, errorMessage}
    SQS-->>N: ReceiveMessage
    N->>N: Compõe e-mail
    N->>+SMTP: SendMail (Nodemailer)
```
